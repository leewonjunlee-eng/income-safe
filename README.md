# 인컴 세이프 · AI 제안 검증 도구

재무설계사가 AI 자산배분안(A안)의 오류·적합성을 점검하고, 수정안(B안)과 같은 시나리오로 비교해 근거를 남겨 채택하는 모바일 웹앱입니다. 서버·로그인 없이 브라우저에만 저장합니다. 금액 단위는 만 원입니다.

```
npm install
npm run dev     # 개발 서버
npm test        # 기획서 6장 정답값 대조 (엔진, 점검 규칙, 확장 기능)
npm run build   # dist/
```

- `src/engine.js` 월별 계산 엔진 (기획서 4장) + 확률 시뮬레이션
- `src/rules.js` AI 원안 점검 7개 규칙, 안전선, 상품·세제, 노후, 이벤트 템플릿
- `public/data/*.json` 고객 프리셋 2명(서윤·민준), 시장 환경 (기준일·출처 포함)
- 외부 연동이 필요한 화면(서류 자동 입력, 마이데이터, 시장 데이터 자동 갱신, 알림 발송)은 설정 → 시연 화면에서 이미지로 제공
